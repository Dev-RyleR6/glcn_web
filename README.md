# GLCN Construction Company Website

Welcome to the official repository for **GLCN Construction Company**. This is a premium, high-end website designed to showcase building expertise with a focus on quality, transparency, and modern aesthetics.

## Vision
*“Where QUALITY is our Priority!”*

Building visions through expert design, general construction, renovations, and comprehensive 3D visualization.

## Key Features
- **Premium Branding**: Corporate blue and white theme inspired by the GLCN brand identity.
- **Modern UI/UX**: 
  - Glassmorphism effects.
  - Smooth "Reveal on Scroll" animations.
  - Custom premium scrollbar.
  - Parallax hero section.
  - Fully responsive across mobile, tablet, and desktop.
- **SEO Optimized**: 
  - Semantic HTML structure.
  - Geo-targeted meta tags (Sibulan, Negros Oriental).
  - Search engine friendly heading hierarchy.
- **Service Portfolio**: Comprehensive visualization of 8 core construction services.
- **Interruption-Free UX**: Floating "Back to Top" button and smooth header transitions.

## Technology Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom design system using variables and modern layout techniques (Flexbox/Grid).
- **JavaScript**: Optimized intersection observers and interactive components.
- **Iconography**: Font Awesome 6.
